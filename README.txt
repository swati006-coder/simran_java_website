JAVA LAB BOOK WEBSITE
=====================

Open index.html in a browser. The layout has category navigation on the left,
a searchable program list, and a source-code detail panel.

Features:
- Search by title or category
- Filter by category
- View complete Java source for each catalogue entry
- Copy source or download an individual .java file
- Output/run notes and source file location

No internet connection or server is required.
